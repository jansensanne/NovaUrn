# NovaUrn

A simple NovaUrn platform for auto scaling.

The key benefits of using NovaUrn include:

- A simple NovaUrn platform for auto scaling

## Key Features

- A simple NovaUrn platform for auto scaling

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/NovaUrn.git`
2. `cd NovaUrn`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
